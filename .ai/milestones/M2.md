# M2 Design direction
**Goal:** design tokens and wireframes for all five pages are approved, so build work never waits on design.
**Read:** handoff/01-to-02.md, context/conventions.md, context/architecture.md (sitemap section)
**Do not read:** content/private/, public/, exports/, other milestone specs, roadmap.md
**Tasks**
1. Propose 2 visual directions (mood, palette, type pairing) that match the brand voice; user picks one.
2. Define tokens in plain CSS variables: color (with contrast check), type scale, spacing, radius.
3. Wireframe Home, Story, Portfolio, CV, Contact (mobile + desktop), with the story-led home hook.
4. Add the approved tokens and wireframe notes to context/architecture.md.
**Done when:** user approves tokens and wireframes; contrast checks pass; notes saved in architecture.md.
**End:** run skill close-milestone.
