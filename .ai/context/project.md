# Project
**Goal:** Personal branding website with CV and portfolio.
**Users:** Owner only (maintainer); visitors are recruiters, clients and collaborators.
**In scope:** Home/about, portfolio pages, CV page, contact links, CV exports (docx, xlsx, JSON).
**Non-goals:** Blog, CMS, user accounts, analytics beyond basics.
**Success looks like:** One JSON edit updates the site and all exports; site is fast, static, and holds no private data.
