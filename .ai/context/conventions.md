# Conventions
- Naming: kebab-case files; JSON keys snake_case.
- Style: minimal, readable, accessible (semantic HTML, contrast, alt text).
- Do: validate cv.json against schema after every edit; keep copy short and concrete.
- Don't: hardcode CV content in pages; put private data in tracked files.
- Output format: JSON for data edits; docx/xlsx/JSON for exports.
- Brand voice: confident, warm, plain English. First person, concrete outcomes over adjectives, short sentences, light storytelling; no jargon without a reason.
